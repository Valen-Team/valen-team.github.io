# API data handling and retention

This page describes the hosted Valen API. For a self-hosted deployment, data handling depends on the operator's configuration.

## Model training

Valen does not use customer API requests or responses to train or fine-tune its models.

## Other uses

Customer data may be processed to handle API requests, return results, prevent fraud and abuse, and monitor service operation and troubleshoot issues.

## Retention and deletion

Retention and deletion depend on the data involved, applicable agreements and legal requirements, and any agreed Zero Data Retention (ZDR) arrangement.

For questions about data handling or retention, contact [liuziyu77@sjtu.edu.cn](mailto:liuziyu77@sjtu.edu.cn).
