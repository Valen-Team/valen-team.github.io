# SGLang deployment

Choose a deployment route and follow its complete installation, startup, and request examples.

| Route | Environment | Start here |
| --- | --- | --- |
| Valen-Team image | Docker with a prebuilt runtime | [Image deployment](./sglang-image.md) |
