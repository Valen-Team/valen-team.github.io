## The decision interface

**Text, images, and video → task instructions and candidates → probabilities.**

Valen supports three question types: **Choice** for named candidates, **Noul** for true/false decisions, and **Score** for ordered grades. JevalKit evaluates these outputs using each benchmark's documented protocol.
