# Cookbook

Complete Roller runs, from the collection command to the published trajectories. Each recipe gives the configuration files, the commands, the results, and the dataset the run produced, so the same pipeline can be run on other models, tasks, and Harnesses.

<CookbookIndex collection="roller" />

## Reproduce a recipe

The configuration files and commands of every recipe are in [`examples/cookbook`](https://github.com/Valen-Team/Roller/tree/main/examples/cookbook) of the Roller repository. [Getting started](/roller/start/getting-started/) covers installation and the first run, and the [CLI reference](/roller/start/cli-reference/) lists every flag a recipe uses.
