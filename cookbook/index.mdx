# Cookbook

Complete Valen applications with runnable code, sample inputs and real-model outputs, grouped by the goal they serve. Every recipe follows the same split: Valen answers typed questions, and code turns the answers into a decision.

<CookbookIndex />

## Run any recipe without an API key

Each remote recipe ships with `caches/<recipe>.json`: the real answers recorded for its sample inputs, keyed by model and request. After you download the bundle, every recipe runs offline and prints the same output as the page. Change a question or an input and the runner calls the model for that request and records the new answer.

```bash
curl -fLO https://valen-team.github.io/cookbook/valen-cookbook.zip
python -m zipfile -e valen-cookbook.zip .
cd valen-cookbook
python rerank.py                       # recorded answers, no key needed
python rerank.py --replay off           # always call the model
```

`--replay only` uses recorded answers only, which is how the site build checks every recipe.
