# From input to business output

The single maintained home for complete Valen application tutorials: runnable code, sample inputs, real-model outputs and uncertainty handling, organized by task. The original notebook cases are reused rather than multiplied into duplicate tutorials.

## Reproduce and navigate

[API documentation](/docs/valen/api/) owns protocols, fields, errors and minimal calls. [Deployment documentation](/docs/valen/choosing/) owns installation and backend configuration. Cookbook owns complete applications.

[Validation, performance and versions](./validation/) · [Migration map](./migration/) · <a href="/cookbook/valen-cookbook.zip">Download scripts and sample data</a>

Pages import the tested source files directly from the website repository. The download bundle is generated from those same files at build time. Scripts never implicitly download models. Media is read only when you explicitly run the commands; no video autoplays.
