This migrates the original local notebook: load one cached model, run the same text questions in **Decisions** and **SystemOne**, then run image and direct video inference. It preserves the original video's separate color and action questions.

`Valen.local` loads an **ONNX bundle**. Native Transformers inference is a separate branch in the shared runner. Both branches require an existing local directory, use CPU FP32, and disable implicit model downloads. Download the pinned model on your intended compute machine using the deployment guide before running. Native loading executes the model repository's Python code (`trust_remote_code=True`); use the revision recorded with the results.

Decisions returns an ordered answer list, a `predicate` probability, and labeled score levels. SystemOne returns an answer mapping, `noul`, and ordered score criteria. String candidate keys and their order are preserved. Scores are probability-weighted **zero-based indices**, not the text of the level label. The adapter call and both raw responses are visible below.

The direct video path uses the model's media configuration (16 uniform frames in the qualified 0.8B bundle); it differs from the one-frame HTTP recipe. It can answer an action question, but one curated clip is not a video accuracy benchmark.

## Install and prepare inputs

Use Python 3.11+. Download the small source bundle, extract it, then install its dependencies:

```bash
curl -fLO https://valen-team.github.io/cookbook/valen-cookbook.zip
python -m zipfile -e valen-cookbook.zip .
cd valen-cookbook
python -m pip install -r requirements.txt
```

For ONNX CPU, also install the local extra. The native branch separately needs Torch/Transformers. These commands run only when you execute them, not when viewing this page.

```bash
python -m pip install 'valen-sdk[onnx,video]==0.2.0'
# Only for --backend native:
python -m pip install torch torchvision transformers
```

Fetch only these small assets when you choose to run (image ≈58 KB, clip ≈395 KB), or provide authorized files with the same names through `--asset-dir`.

```bash
curl -fL https://raw.githubusercontent.com/Valen-Team/Valen/main/assets/cookbook/sheep.jpg -o sheep.jpg
curl -fL https://raw.githubusercontent.com/Valen-Team/Valen/main/assets/cookbook/momos.mp4 -o momos.mp4
```

## Run

```bash
python local_inference.py --backend onnx --model /path/to/Valen-0.8B-ONNX --asset-dir . --output local.json
# Alternatively, an already downloaded native model:
python local_inference.py --backend native --model /path/to/Valen-0.8B --asset-dir . --output native.json
```
