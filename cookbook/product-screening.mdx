A marketplace sells photographic animal prints. It receives two listing records pointing to the same sheep photo: one claims a flock of sheep, the other a clowder of cats. This intentionally small test lets you verify both the matching and mismatching business branches without inventing a second image.

The original notebook's animal-group question is reused. The program asks it once per image, compares the selected group with each listing's declared category, and ranks listings by the probability of their declared group. Outputs are `accept`, `category_mismatch`, or `manual_review`; no listing is deleted. The choice needs selected probability ≥ 0.8 and a top-two gap ≥ 0.2. A weak result sends **both** listings to review.

This validates category consistency for this sample, not product quality, copyright ownership, image safety, or real marketplace accuracy. A photo of sheep is being used as a print product; it is not a general product catalog dataset. Use a labeled product set and your own business taxonomy before expanding the task.

## Install and prepare inputs

Use Python 3.11+. Download the small source bundle, extract it, then install its dependencies:

```bash
curl -fLO https://valen-team.github.io/cookbook/valen-cookbook.zip
python -m zipfile -e valen-cookbook.zip .
cd valen-cookbook
python -m pip install -r requirements.txt
```

Fetch only these small assets when you choose to run (image ≈58 KB, clip ≈395 KB), or provide authorized files with the same names through `--asset-dir`.

```bash
curl -fL https://raw.githubusercontent.com/Valen-Team/Valen/main/assets/cookbook/sheep.jpg -o sheep.jpg
```

## Run

The recorded answers in `caches/product_screening.json` let the script run without an API key; `--replay off` calls the [free hosted API](/docs/valen/api/) instead.

```bash
python product_screening.py --asset-dir . --output result.json
python product_screening.py --replay off --model valen-2b --asset-dir . --output result.json
# An existing local HTTP deployment instead:
python product_screening.py --replay off --base-url http://127.0.0.1:8000/v1 --model valen --asset-dir . --output result.json
```

For direct ONNX execution, use `--backend onnx --model /path/to/Valen-0.8B-ONNX` and first install `valen-sdk[onnx,video]==0.2.0`. Connect a GGUF service through `--backend remote`; a GGUF file is not a `Valen.local` model.
