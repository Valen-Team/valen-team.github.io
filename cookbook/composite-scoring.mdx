A marketplace asks sellers for a good main photo. "Is this a good photo?" hides what makes it good, and different storefronts care about different things. Valen scores each photo once on three dimensions; code combines them with weights each storefront can change without another model call.

## How it works

Three score questions, each with three levels described as situations a person could recognize:

| Dimension | Levels |
| --- | --- |
| `lighting` | poor · fair · good |
| `background` | cluttered · plain · studio |
| `framing` | cut off · loose · centered |

A score runs from 0 to 2 over three levels; code divides by 2 so each dimension is on 0–1, then takes a weighted sum per storefront:

| Profile | lighting | background | framing |
| --- | --- | --- | --- |
| `marketplace` | 0.3 | 0.2 | 0.5 |
| `premium_shop` | 0.3 | 0.5 | 0.2 |

## Run it

Download the bundle once. The recorded answers in `caches/composite_scoring.json` let the script run without an API key; `--replay off` calls the [free hosted API](/docs/valen/api/) instead.

```bash
curl -fLO https://valen-team.github.io/cookbook/valen-cookbook.zip
python -m zipfile -e valen-cookbook.zip .
cd valen-cookbook && python -m pip install -r requirements.txt
python composite_scoring.py
python composite_scoring.py --replay off --base-url https://api.valen-team.workers.dev/v1
```
