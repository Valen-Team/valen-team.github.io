This migrates the original API notebook without duplicating the application tutorials. Send a delivery-address message, identify the animal group in an image, and label the sauce color in one sampled video frame. The output contains named answers and the exact sampled frame position.

The HTTP client uses **Decisions**. The API accepts an image data URL; the tutorial extracts a frame before sending the video example. This is not direct video inference on the hosted service. Set `VALEN_API_KEY` only if your chosen deployment requires it.

## Install and prepare inputs

Use Python 3.11+. Download the small source bundle, extract it, then install its dependencies:

```bash
curl -fLO https://valen-team.github.io/cookbook/valen-cookbook.zip
python -m zipfile -e valen-cookbook.zip .
cd valen-cookbook
python -m pip install -r requirements.txt
```

Fetch only these small assets when you choose to run (image ≈58 KB, clip ≈395 KB), or provide authorized files with the same names through `--asset-dir`.

```bash
curl -fL https://raw.githubusercontent.com/Valen-Team/Valen/main/assets/cookbook/sheep.jpg -o sheep.jpg
curl -fL https://raw.githubusercontent.com/Valen-Team/Valen/main/assets/cookbook/momos.mp4 -o momos.mp4
```

## Run

The recorded answers in `caches/api_quickstart.json` let the script run without an API key; `--replay off` calls the [free hosted API](/docs/valen/api/) instead.

```bash
python api_quickstart.py --asset-dir . --output result.json
python api_quickstart.py --replay off --model valen-2b --asset-dir . --output result.json
# An existing local HTTP deployment instead:
python api_quickstart.py --replay off --base-url http://127.0.0.1:8000/v1 --model valen --asset-dir . --output result.json
```

For direct ONNX execution, use `--backend onnx --model /path/to/Valen-0.8B-ONNX` and first install `valen-sdk[onnx,video]==0.2.0`. Connect a GGUF service through `--backend remote`; a GGUF file is not a `Valen.local` model.
