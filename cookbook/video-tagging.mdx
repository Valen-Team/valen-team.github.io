A clip index needs a searchable visual tag. Read the original short dumpling clip, extract its middle frame, ask the original sauce-color question, and emit a JSON annotation containing the clip ID, tag, confidence, frame index, timestamp and total decoded frames.

This recipe deliberately produces a **single-frame visual attribute**. It does not infer the clip's action or assign the tag to every moment. Direct video and the original action question are retained in the local-inference tutorial. The bounded decoder counts at most 1800 frames, limits frame dimensions to 4K, decodes in two passes, and holds only one selected image. It converts the selected frame to a JPEG with longest edge ≤ 512 pixels before sending one image to the backend.

Emit the tag only when its selected probability ≥ 0.8 and the top-two gap ≥ 0.2. Otherwise emit no tag and set `manual_review`. Confidence can prioritize the review queue, but it is not a calibrated correctness estimate. Sample multiple time segments and validate temporal coverage if your application needs clip-wide labels.

## Install and prepare inputs

Use Python 3.11+. Download the small source bundle, extract it, then install its dependencies:

```bash
curl -fLO https://valen-team.github.io/cookbook/valen-cookbook.zip
python -m zipfile -e valen-cookbook.zip .
cd valen-cookbook
python -m pip install -r requirements.txt
```

Fetch only these small assets when you choose to run (image ≈58 KB, clip ≈395 KB), or provide authorized files with the same names through `--asset-dir`.

```bash
curl -fL https://raw.githubusercontent.com/Valen-Team/Valen/main/assets/cookbook/momos.mp4 -o momos.mp4
```

## Run

```bash
python video_tagging.py --backend remote --model valen-2b --asset-dir . --output result.json
# An existing local HTTP deployment instead:
python video_tagging.py --backend remote --base-url http://127.0.0.1:8000/v1 --model valen --asset-dir . --output result.json
```

For direct ONNX execution, use `--backend onnx --model /path/to/Valen-0.8B-ONNX` and first install `valen-sdk[onnx,video]==0.2.0`. Connect a GGUF service through `--backend remote`; a GGUF file is not a `Valen.local` model.
