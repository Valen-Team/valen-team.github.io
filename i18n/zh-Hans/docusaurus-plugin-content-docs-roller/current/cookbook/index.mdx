# Cookbook

完整的 Roller 运行记录，从采集命令到发布的轨迹。每篇给出配置文件、命令、结果和这次 run 产出的数据集，同一套流程可以换用其他模型、任务和 Harness。

<CookbookIndex collection="roller" />

## 复现一篇教程

每篇教程的配置文件和命令位于 Roller 仓库的 [`examples/cookbook`](https://github.com/Valen-Team/Roller/tree/main/examples/cookbook)。安装和首次运行见[快速上手](/roller/start/getting-started/)，教程用到的参数见 [CLI 参数参考](/roller/start/cli-reference/)。
