# API 数据处理与保留

本页面介绍 Valen 托管 API 的数据处理。自行部署时，数据处理方式取决于部署者的配置。

## 模型训练

Valen 不使用客户的 API 请求或响应来训练或微调模型。

## 其他用途

客户数据可能用于处理 API 请求、返回结果、防范欺诈和滥用，以及监测服务运行情况和排查故障。

## 保留与删除

数据的保留与删除取决于涉及的数据、适用协议和法律要求，以及任何已约定的零数据保留（ZDR）安排。
