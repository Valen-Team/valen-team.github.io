# 一起构建

欢迎贡献模型、评测任务、数据、文档和智能体应用。

## 选择对应仓库

- **[Valen](https://github.com/Valen-Team/Valen)：**模型实现、推理、训练、视觉决策与相关文档。
- **[JevalKit](https://github.com/Valen-Team/JevalKit)：**模型适配器、Benchmark 集成、评分与评测结果。

## 报告问题

请提供仓库版本、环境、完整命令和最小可复现示例。涉及评测结果时，请提供模型检查点、数据版本或摘要，以及评分协议。

[提交 Valen Issue](https://github.com/Valen-Team/Valen/issues) · [提交 JevalKit Issue](https://github.com/Valen-Team/JevalKit/issues)

## 完善评测覆盖

推荐 Benchmark 或已经发布的决策模型时，请链接原始发布并说明输入输出接口。详见[接入模型](/zh-Hans/docs/jevalkit/models/)与 [Benchmark 协议](/zh-Hans/docs/jevalkit/benchmarks/)。

## 改进文档

在对应项目仓库反馈不清晰的步骤或失效示例。本站技术参考页从源仓库同步，并保留来源信息。
