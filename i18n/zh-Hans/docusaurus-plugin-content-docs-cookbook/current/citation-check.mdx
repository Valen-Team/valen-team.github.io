一篇关于某城市共享单车的文章草稿提出了七条论断，每条都引用了一份报告、市议会会议记录或一项调查。发布前，每条论断都要对照它引用的段落核查。来源明确支持的论断通过；被反驳和无依据的论断退回给作者；其余的交给编辑。

## 工作原理

每条论断与其来源组成一个输入，配两道判断题：

| 问题 | 类型 |
| --- | --- |
| `supported`：来源陈述了论断所说的内容 | predicate |
| `contradicted`：来源陈述的内容与论断相冲突 | predicate |

“没有依据”和“被反驳”会导向不同的动作，所以分成两道题来问。真值表：

| `contradicted` | `supported` | 状态 |
| --- | --- | --- |
| 0.7 及以上 | 任意 | `contradicted` |
| 低于 0.7 | 0.7 及以上 | `supported` |
| 低于 0.3 | 低于 0.3 | `unsupported` |
| 其他 | 其他 | `escalate` |

## 改成你自己的

- 把数量表述（"most"、"a third"、"doubled"）与来源中的数字作比较属于算术：在代码里提取数字并比较，Valen 只负责判断文本说了什么。
- 把 `escalate` 的论断交给编辑或推理模型；其余的都在一次低成本的处理中定下来。
