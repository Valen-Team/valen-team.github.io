本教程迁移旧 API Notebook：发送修改收货地址的文本、识别图片中的动物群体、判断视频中间帧里的酱汁颜色。输出包含命名答案和真实抽帧位置。完整业务流程分别在后面的三个应用教程维护。

HTTP 客户端使用 **Decisions**。图片以 data URL 传入；视频示例先抽帧再发送图片，不代表托管 API 支持直接视频推理。仅在所选服务需要认证时设置 `VALEN_API_KEY`。

## 安装与输入

Python 3.11+。先下载小型源文件包并解压，然后安装所需依赖：

```bash
curl -fLO https://valen-team.github.io/cookbook/valen-cookbook.zip
python -m zipfile -e valen-cookbook.zip .
cd valen-cookbook
python -m pip install -r requirements.txt
```

明确执行后才获取以下小素材（图片约 58 KB，视频约 395 KB）；也可将有权使用的同名文件放在 `--asset-dir` 指定目录。

```bash
curl -fL https://raw.githubusercontent.com/Valen-Team/Valen/main/assets/cookbook/sheep.jpg -o sheep.jpg
curl -fL https://raw.githubusercontent.com/Valen-Team/Valen/main/assets/cookbook/momos.mp4 -o momos.mp4
```

## 运行

```bash
python api_quickstart.py --backend remote --model valen-2b --asset-dir . --output result.json
# An existing local HTTP deployment instead:
python api_quickstart.py --backend remote --base-url http://127.0.0.1:8000/v1 --model valen --asset-dir . --output result.json
```

本地 ONNX 也可直接运行：把参数改为 `--backend onnx --model /path/to/Valen-0.8B-ONNX`，并先安装 `valen-sdk[onnx,video]==0.2.0`。GGUF 服务通过 `--backend remote` 接入；不能把 GGUF 文件传给 `Valen.local`。
