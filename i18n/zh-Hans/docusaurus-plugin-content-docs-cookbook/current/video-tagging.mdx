视频索引需要可检索的视觉标签。读取旧教程的饺子短视频，抽取中间帧，复用酱汁颜色问题，生成包含片段 ID、颜色标签、置信度、帧索引、时间戳与总解码帧数的 JSON 标注。

本例只输出**单帧视觉属性**，不推断整段视频的动作，也不把标签赋给所有时刻。直接视频及原动作问题保留在本地推理教程中。解码器最多计数 1800 帧、限制单帧为 4K、分两遍解码，只保留目标图像；提交前将该帧转换为最长边不超过 512 像素的 JPEG，后端仅收到一张图片。

选中概率至少为 0.8 且前两名概率差至少为 0.2 时才输出标签，否则输出空标签并进入 `manual_review`。置信度可用于安排审核优先级，但不是经过校准的正确率。需要覆盖整段视频时，应抽取多个时间片段并验证时间覆盖率。

## 安装与输入

Python 3.11+。先下载小型源文件包并解压，然后安装所需依赖：

```bash
curl -fLO https://valen-team.github.io/cookbook/valen-cookbook.zip
python -m zipfile -e valen-cookbook.zip .
cd valen-cookbook
python -m pip install -r requirements.txt
```

明确执行后才获取以下小素材（图片约 58 KB，视频约 395 KB）；也可将有权使用的同名文件放在 `--asset-dir` 指定目录。

```bash
curl -fL https://raw.githubusercontent.com/Valen-Team/Valen/main/assets/cookbook/momos.mp4 -o momos.mp4
```

## 运行

`caches/video_tagging.json` 中录制的回答让脚本无需 API key 即可运行；加 `--replay off` 则改为调用[免费托管 API](/zh-Hans/docs/valen/api/)。

```bash
python video_tagging.py --asset-dir . --output result.json
python video_tagging.py --replay off --model valen-2b --asset-dir . --output result.json
# 改用已有的本地 HTTP 部署：
python video_tagging.py --replay off --base-url http://127.0.0.1:8000/v1 --model valen --asset-dir . --output result.json
```

本地 ONNX 也可直接运行：把参数改为 `--backend onnx --model /path/to/Valen-0.8B-ONNX`，并先安装 `valen-sdk[onnx,video]==0.2.0`。GGUF 服务通过 `--backend remote` 接入；不能把 GGUF 文件传给 `Valen.local`。
