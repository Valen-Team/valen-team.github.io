一个市场出售动物摄影挂画。两个商品记录使用同一张羊群照片：第一个声明为羊群，第二个声明为猫群。这个小样例不伪造第二张图片，同时覆盖分类匹配与不匹配两条业务分支。

复用旧 Notebook 的动物群体问题，每张图片只推理一次。程序将识别结果与商品声明分类对比，并按声明分类的匹配概率排序，输出 `accept`、`category_mismatch` 或 `manual_review`，不会删除商品。选中概率至少为 0.8 且前两名概率差至少为 0.2 才自动判断；结果不确定时两个商品均进入人工复核。

本例验证该素材的分类一致性，不验证商品质量、版权归属、图片安全性或真实市场准确率。这里将羊群照片当作挂画商品展示，并非完整商品数据集。扩展前应使用自有标注商品集和实际业务分类体系。

## 安装与输入

Python 3.11+。先下载小型源文件包并解压，然后安装所需依赖：

```bash
curl -fLO https://valen-team.github.io/cookbook/valen-cookbook.zip
python -m zipfile -e valen-cookbook.zip .
cd valen-cookbook
python -m pip install -r requirements.txt
```

明确执行后才获取以下小素材（图片约 58 KB，视频约 395 KB）；也可将有权使用的同名文件放在 `--asset-dir` 指定目录。

```bash
curl -fL https://raw.githubusercontent.com/Valen-Team/Valen/main/assets/cookbook/sheep.jpg -o sheep.jpg
```

## 运行

`caches/product_screening.json` 中录制的回答让脚本无需 API key 即可运行；加 `--replay off` 则改为调用[免费托管 API](/zh-Hans/docs/valen/api/)。

```bash
python product_screening.py --asset-dir . --output result.json
python product_screening.py --replay off --model valen-2b --asset-dir . --output result.json
# 改用已有的本地 HTTP 部署：
python product_screening.py --replay off --base-url http://127.0.0.1:8000/v1 --model valen --asset-dir . --output result.json
```

本地 ONNX 也可直接运行：把参数改为 `--backend onnx --model /path/to/Valen-0.8B-ONNX`，并先安装 `valen-sdk[onnx,video]==0.2.0`。GGUF 服务通过 `--backend remote` 接入；不能把 GGUF 文件传给 `Valen.local`。
