一个电商平台要求卖家上传一张好的主图。"Is this a good photo?" 这样的问法掩盖了照片好在哪里，而不同店铺看重的方面也不一样。Valen 对每张照片在三个维度上评分一次；代码用权重把它们组合起来，每个店铺都可以修改权重，无需再次调用模型。

## 工作原理

三道评分题，每道有三个等级，每个等级都描述成人一眼能认出的情形：

| 维度 | 等级 |
| --- | --- |
| `lighting` | 差 · 一般 · 好 |
| `background` | 杂乱 · 素净 · 影棚 |
| `framing` | 被裁切 · 松散 · 居中 |

评分题在三个等级上取值 0 到 2；代码除以 2，让每个维度落在 0–1 之间，再按店铺计算加权和：

| 配置 | lighting | background | framing |
| --- | --- | --- | --- |
| `marketplace` | 0.3 | 0.2 | 0.5 |
| `premium_shop` | 0.3 | 0.5 | 0.2 |

## 运行

先下载一次示例包。`caches/composite_scoring.json` 中录制的回答让脚本无需 API key 即可运行；加 `--replay off` 则改为调用[免费托管 API](/zh-Hans/docs/valen/api/)。

```bash
curl -fLO https://valen-team.github.io/cookbook/valen-cookbook.zip
python -m zipfile -e valen-cookbook.zip .
cd valen-cookbook && python -m pip install -r requirements.txt
python composite_scoring.py
python composite_scoring.py --replay off --base-url https://api.valen-team.workers.dev/v1
```

## 改成你自己的
