# Cookbook

Valen 完整应用教程：可运行代码、样例输入和真实模型输出，按要解决的目标分组。每篇都遵循同一个分工：Valen 回答带类型的问题，代码把回答变成决策。

## 不用 API key 也能运行

每篇调用远程服务的教程都附带 `caches/<recipe>.json`，里面是样例输入的真实回答，按模型和请求内容索引。下载后所有教程都能离线运行，输出与页面一致。改动问题或输入后，运行器会对新请求调用模型并记录回答。

```bash
curl -fLO https://valen-team.github.io/cookbook/valen-cookbook.zip
python -m zipfile -e valen-cookbook.zip .
cd valen-cookbook
python rerank.py                       # 使用录制的回答，无需 key
python rerank.py --replay off           # 每次都调用模型
```

`--replay only` 只使用录制的回答，官网构建时就用这种方式检查每篇教程。
