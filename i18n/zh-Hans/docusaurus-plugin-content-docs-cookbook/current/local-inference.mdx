本教程迁移旧本地 Notebook：加载一个缓存模型，用 **Decisions** 和 **SystemOne** 运行相同文本问题，再执行图片与直接视频推理。保留原视频独有的颜色和动作两道题。

`Valen.local` 加载的是 **ONNX 模型包**。原版 Transformers 使用共享运行器中的另一个分支。两个分支均要求已有本地模型目录，采用 CPU FP32，并禁止隐式下载模型。请先按部署文档在实际计算机器上下载固定 revision。原版加载会执行模型仓库 Python 代码（`trust_remote_code=True`），应使用结果记录中的 revision。

Decisions 返回有序答案列表、`predicate` 概率与带标签的评分等级；SystemOne 返回答案字典、`noul` 与有序评分标准。字符串候选键及顺序保持一致。score 是**从零开始的等级索引的概率加权平均**，不是 label 文本中的数字。下方代码及实际结果展示了映射与两种原始响应。

直接视频使用模型的媒体配置，已验证的 0.8B 包采用 16 帧均匀采样，与单帧 HTTP 教程不同。它可以回答动作问题，但一段精选视频不能作为视频准确率基准。

## 安装与输入

Python 3.11+。先下载小型源文件包并解压，然后安装所需依赖：

```bash
curl -fLO https://valen-team.github.io/cookbook/valen-cookbook.zip
python -m zipfile -e valen-cookbook.zip .
cd valen-cookbook
python -m pip install -r requirements.txt
```

ONNX CPU 还需安装本地 extra；原版分支另需 Torch/Transformers。这里只展示安装命令，不会在网页访问时下载任何依赖或模型。

```bash
python -m pip install 'valen-sdk[onnx,video]==0.2.0'
# Only for --backend native:
python -m pip install torch torchvision transformers
```

明确执行后才获取以下小素材（图片约 58 KB，视频约 395 KB）；也可将有权使用的同名文件放在 `--asset-dir` 指定目录。

```bash
curl -fL https://raw.githubusercontent.com/Valen-Team/Valen/main/assets/cookbook/sheep.jpg -o sheep.jpg
curl -fL https://raw.githubusercontent.com/Valen-Team/Valen/main/assets/cookbook/momos.mp4 -o momos.mp4
```

## 运行

```bash
python local_inference.py --backend onnx --model /path/to/Valen-0.8B-ONNX --asset-dir . --output local.json
# Alternatively, an already downloaded native model:
python local_inference.py --backend native --model /path/to/Valen-0.8B --asset-dir . --output native.json
```
